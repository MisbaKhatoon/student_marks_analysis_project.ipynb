# 🎓 Student Marks Analysis Using Python

## 📌 About the Project
This project analyzes student marks using Python to understand academic performance. It calculates average marks, identifies the highest and lowest scores, and analyzes pass percentages and grades.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib (for visualizations, if used)

## ✨ Features
- Student-wise and subject-wise marks analysis
- Calculation of average marks
- Identification of highest and lowest scores
- Pass percentage and grade distribution
- Identification of students who need academic support

## 🎯 Objective
To use Python for analyzing student performance and generating meaningful insights from academic data.

## 🚀 Learning Outcome
This project helped me practice Python programming, data manipulation, and basic data analysis.
